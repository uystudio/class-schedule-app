发布流程说明

①
生成发布单

在上面的管理台里选 APK、填信息、生成并复制发布单。

②
发给豆包执行

把发布单和新版 APK 文件一起发给豆包，说“发布新版”。豆包会：上传 APK → 更新下载页 → 更新检查接口 → 验证。

③
发布完成

同学访问下载站就是新版；装过旧版的同学，打开 App 会自动收到“发现新版本”的提示。

为什么上传 APK 要交给豆包？新版 APK 有 50 多 MB，网页和 GitHub 接口都传不了这么大的文件，只有 git 能传。所以网页负责“算好一切信息”，传文件这步由豆包代做，2 分钟搞定。
